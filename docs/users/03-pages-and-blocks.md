# 03. Страницы и блоки

**Главный инструмент** наполнения сайта. Страницы состоят из блоков, блоки —
кирпичики контента (заголовок, текст, галерея, статистика, кнопка-призыв).

## Концепция в одной картинке

```
Страница «О колледже»
├── Блок «Hero» — большой баннер сверху
├── Блок «Статистика» — цифры «75 лет», «15 000 выпускников»
├── Блок «Контент» — абзац с историей
├── Блок «Преимущества» — 4 карточки с иконками
└── Блок «CTA» — кнопка «Поступить сейчас»
```

Каждый блок — отдельная единица. Его можно передвинуть, выключить, скопировать
его данные в другой блок. Порядок блоков — порядок их появления на странице.

## Где это находится

Сайдбар → **Контент → Блоки** (или `/admin/blocks`).

Открывается список всех блоков всех страниц, сгруппированный по странице.
Сверху — фильтры: по странице, по типу блока, по статусу, поиск.

### Сортировка

Список отсортирован «свежие первыми» — страница с самой недавней правкой
наверху, внутри страницы — последний редактированный блок сверху. Так
работать с только что правленым блоком проще всего: он всегда на виду.

### Поиск

Поле «поиск» — ищет не только по названию блока, но и по:
- содержимому (заголовок / подзаголовок / текст)
- данным внутри (ссылки, элементы карточек, пункты списка)
- всем трём языкам (ru / kk / en)
- лейблу страницы — введи «документы» и найдёшь блоки на странице
  «Отчёты и прозрачность»

## Как устроена карточка блока в списке

```
┌───────────────────────────────────────────────────┐
│ 🟢 Активен   [Опубликовано]                        │
│                                                    │
│ «Hero секция: Добро пожаловать»        #1          │
│ Тип: hero · home                                   │
│                                                    │
│                        [Редактировать] [Удалить]   │
└───────────────────────────────────────────────────┘
```

- 🟢/⚪ — «Активен/Скрыт» (переключатель на сайте).
- «Опубликовано / Черновик / В архиве» — статус.
- Название блока = заголовок (`title`) на русском.
- `#1` — порядковый номер на странице.
- `hero · home` — тип блока и страница, к которой он прикреплён.

## Создать новый блок

1. На списке нажми «**+ Новый блок**» справа сверху.
2. Выбери **страницу** из выпадающего списка. Видишь только страницы,
   которые реально есть на сайте (draft-страницы скрыты).
3. Выбери **тип блока** — откроется визуальный пикер с категориями:
   «Hero», «Контент», «Списки», «Системные» и т.д. У каждого типа есть
   короткое описание — что он делает и когда его использовать.
4. Нажми «Создать».

## Форма редактирования блока

Форма разделена на три вкладки сверху:

### Вкладка «Контент» — переводимые поля

- **Заголовок** — одна строка, большой текст (обычно `h1` или `h2` на сайте).
- **Подзаголовок** — пара строк помельче.
- **Содержимое** — визуальный редактор: абзацы, жирный, курсив, ссылки,
  списки, картинки, таблицы.

Сверху вкладки — переключатель языка: `ru / kk / en`. Заполняй все три, если
хочешь, чтобы блок показывался на всех версиях сайта. Если какой-то язык
пустой, сайт подставляет русский как запасной.

### Вкладка «Данные»

Здесь живёт структурированный контент, специфичный для типа блока:

- **Hero** — картинка фона, слайды, кнопки («текст + ссылка»).
- **Статистика** — список элементов `{число, подпись, иконка}`.
- **Галерея** — набор изображений с подписями.
- **Преимущества** — карточки с иконкой + заголовком + описанием.
- **Ссылки** — список ссылок с иконкой, URL, заголовком, описанием.
- **Timeline** — события хронологии: `{дата, заголовок, текст}`.

В большинстве типов редактор **визуальный**: добавляешь пункты кнопкой
«+ элемент», перетаскиваешь, удаляешь. Для редких типов или кастомных данных
есть fallback в виде JSON-редактора — разработчик тебе скажет, что туда
писать.

### Вкладка «Настройки»

Мелкие опции конкретного типа блока (например, «показать кнопки» или «тёмный
фон»). Обычно можно не трогать.

## Сайдбар справа (Публикация)

Справа от формы — карточка «**Публикация**» со всеми переключателями:

- **Статус** — `Черновик / Опубликовано / В архиве`.
  - Черновик: виден тебе в админке, **не виден на сайте**.
  - Опубликовано: виден на сайте.
  - В архиве: спрятан в списке, можно вернуть позже.
- **Активен** — галочка. Если снять, блок вообще не появится на сайте, даже
  если статус «Опубликовано».
- **Опубликовать в** — дата и время автопубликации. См. [раздел 11](./11-scheduled-publishing.md).
- **Снять с публикации в** — дата автоскрытия.
- **Сохранить** — большая красная кнопка.
- **История изменений** — ссылка на [ревизии](./10-revisions.md) этого блока.
- **Автосохранение** — маленькая подпись «черновик автосохранён в HH:MM».
  Если браузер упадёт, при следующем заходе админка предложит
  восстановить.

## Предпросмотр (iframe)

В редактировании блока справа от вкладок есть кнопка «**Предпросмотр**». Клик
добавляет сбоку iframe с публичной страницей. Каждый раз, когда ты сохраняешь,
iframe автоматически обновляется — видишь изменение в контексте всей
страницы, не переключаясь между вкладками.

Кнопка `⤴` над iframe открывает страницу в новой вкладке. Кнопка `↻` — вручную
обновить (например, если меняются данные за пределами этого блока).

## Порядок блоков на странице

В списке блоков (фильтр «Страница = конкретная страница») — блоки идут в
порядке `sort_order`. Чтобы изменить порядок, открой блок и в поле
«порядок сортировки» поставь нужное число:

- Меньше → выше.
- Больше → ниже.

Если у двух блоков одинаковый `sort_order` — порядок по дате изменения.

## Удалить блок

Открой блок → в шапке справа красная кнопка «Удалить». Удаление моментальное,
но блок **появится в [истории изменений](./10-revisions.md)** — восстановить
можно там.

Если блок нужен только «спрятать на время» — лучше снять галочку «Активен»
или поставить статус «В архиве».

## Частые ситуации

### «Моё изменение не видно на сайте»

1. Статус = «Опубликовано»? (не «Черновик»)
2. Галочка «Активен» включена?
3. `publish_at` не в будущем? (см. [раздел 11](./11-scheduled-publishing.md))
4. [Сбросить кэш](./15-cache.md).

### «Я случайно всё удалил»

Открой [историю изменений](./10-revisions.md) этого блока и нажми
«Восстановить» на нужной ревизии.

### «Я не вижу свою страницу в выпадашке»

Страница скрыта. Зайди в «Страницы» (в сайдбаре) и смени статус на
«Опубликовано».
