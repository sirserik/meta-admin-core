# 07. Медиатека

Единое хранилище картинок (и файлов) сайта. Загружаешь один раз — используешь
где угодно.

## Где это

**Сайдбар → Система → Медиа** (`/admin/media`).

## Что можно загружать

- **Изображения** — JPG, PNG, WebP, GIF, SVG.
- **Документы** — PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX.
- **Архивы** — ZIP (только для раздачи через ссылки).

Максимальный размер файла зависит от настроек сервера (обычно 20 МБ на
файл). Если превысил — появится ошибка.

## Интерфейс

```
┌──────────┬──────────┬──────────┬──────────┐
│ [загруз.] │ [поиск]  │ [фильтр] │ Всего: 87│
├──────────┼──────────┼──────────┼──────────┤
│ 🖼 фото1 │ 🖼 фото2 │ 🖼 лого  │ 📄 док.  │
│ 800×600 │ 1200×800 │ 300×300  │ PDF 2мб   │
└──────────┴──────────┴──────────┴──────────┘
```

Сетка миниатюр. Клик открывает модалку с деталями и кнопками.

## Загрузить файл

Два способа:

1. **Кнопка «Загрузить»** — открывает выбор файла.
2. **Перетаскивание** — бросай файл из Finder / Проводника прямо на область
   медиатеки. Можно сразу несколько.

После загрузки:
- Файл оптимизируется: изображения сжимаются и **конвертируются в WebP**
  (меньше весят, быстрее загружаются). Оригинал при этом удаляется.
- Имя автоматически безопасно преобразуется: русские символы / пробелы /
  спецзнаки заменяются на `_`. Например, `Моя фотка (2).jpg` →
  `time-moya-fotka-2.webp`.

## Детали файла

Клик по миниатюре открывает модалку:

- **Превью** — само изображение или иконка типа.
- **Имя файла** — можно скопировать.
- **Размер и разрешение** — для картинок.
- **URL** — абсолютная ссылка. Нажми «📋 Копировать», чтобы вставить в
  нужное поле админки или на сайт.
- **Alt-текст** — описание для скринридеров и SEO. Заполняй всегда, когда
  картинка не декоративная.
- **Кнопка «Удалить»** — красная, внизу.

## Удалить файл

После удаления файл **навсегда исчезает с диска**. Если он был вставлен в
какую-то страницу — там появится «битая» картинка (красный крестик).
Проверь перед удалением, что файл больше не используется.

Если нужно «спрятать, но сохранить» — переименуй в что-то вроде
`ARCHIVED-{имя}` или выгрузи в отдельную папку на своём компе, а потом
удали из медиатеки.

## Поиск

Поле «поиск» сверху — ищет по имени файла. Удобно, когда медиатека разрослась
до нескольких сотен записей.

## Как вставить картинку в блок

### В визуальный редактор текста (`content`)

1. В тулбаре типтапа нажми 📷 (иконка изображения).
2. Появится выбор: либо «загрузить новое», либо «из медиатеки».
3. Из медиатеки — выбери уже загруженный файл.
4. Картинка встанет в курсор.

### В поле типа «картинка» в данных блока

На форме блока в разделе «Данные» поле типа «изображение» — показывает либо
превью существующего, либо кнопку «Выбрать файл». Клик открывает
медиатеку/загрузку.

### В пункт галереи

В блоке `gallery` для каждого элемента — своё поле с картинкой. Добавляешь
картинку так же, как в поле типа «картинка».

## Размеры изображений

Система **не обрезает** загруженные изображения — они хранятся в исходном
разрешении. Шаблон сайта просто масштабирует их через CSS/HTML-атрибуты.

Чтобы сайт грузился быстро:
- **Не заливай картинки больше 2000×1500 пикселей**, если они не нужны в
  высоком разрешении.
- **Не заливай фотки «из мобилки» в 4000×3000** — сожми заранее.
- **WebP конвертация** делается автоматически при загрузке.

## Focal points (точка фокуса) — для ~специальных шаблонов~

Если у блока на сайте картинка обрезается по-разному для десктопа и мобилки,
можно указать **точку фокуса** — ту часть фото, которая **должна остаться
видимой при любой обрезке** (например, лицо человека на фото).

1. В форме блока или ресурса, где есть такое поле, кликни по картинке
   на месте «важной точки».
2. Появится крестик-метка. Дальше сайт при обрезке оставит её в кадре.
3. Сохранить блок.

Не все сайты используют focal points — уточни у разработчика, на каких
шаблонах это поддержано.

## Где физически лежат файлы

- Картинки: `storage/app/public/` на сервере, доступны через
  `/media/{путь}` или `/storage/{путь}`.
- Медиатека показывает публичные URL — по ним можно сразу вставлять в
  любое поле.
