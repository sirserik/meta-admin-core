# Админка для редакторов

Это руководство для тех, кто **наполняет сайт** — добавляет страницы,
редактирует блоки, загружает фотографии, настраивает формы обратной связи.
Программирование не нужно: всё делается через визуальный интерфейс.

## С чего начать

1. Прочитай [«Вход и первое знакомство»](./01-getting-started.md) — как попасть
   в админку и как устроен экран.
2. Дальше смотри по задаче:
   - Добавить/изменить контент на странице → [«Страницы и блоки»](./03-pages-and-blocks.md)
   - Опубликовать что-то через неделю → [«Запланированная публикация»](./11-scheduled-publishing.md)
   - Откатить случайное изменение → [«История изменений»](./10-revisions.md)
   - Настроить форму записи / заявки → [«Формы и заявки»](./08-forms.md)

## Если что-то пошло не так

- Спроси администратора сайта.
- Посмотри [«Сброс кэша»](./15-cache.md) — иногда старая страница просто
  застряла в кэше и проблема уйдёт после сброса.
- Если потерял текст — загляни в [«Историю изменений»](./10-revisions.md).
