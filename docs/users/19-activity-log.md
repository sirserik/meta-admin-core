# 19. Журнал активности

«Кто что когда сделал» — автоматический лог всех действий в админке.

## Где

**Сайдбар → Система → Активность** (`/admin/activity`).

## Зачем нужен

- **Отследить**, кто поменял блок, который теперь не работает.
- **Понять**, когда именно было создано/удалено что-то.
- **Показать** руководству, что работа идёт (сколько правок за неделю).
- **Расследовать** инциденты безопасности (чужой вход, странные удаления).

## Список записей

```
┌─────────────────────────────────────────────────┐
│ 19.04.2026 14:23                                │
│ Иван Петров (ivan@etec.kz)                      │
│ создал блок «Hero» на странице home            │
├─────────────────────────────────────────────────┤
│ 19.04.2026 14:19                                │
│ Гульнара Ахметова                                │
│ обновила страницу «О колледже»                   │
├─────────────────────────────────────────────────┤
│ 19.04.2026 14:05                                │
│ система (cron)                                   │
│ опубликовала блок #143 по расписанию             │
└─────────────────────────────────────────────────┘
```

## Фильтры

- По автору (пользователь).
- По типу действия: `created` / `updated` / `deleted` / `published`.
- По ресурсу / таблице (блоки / страницы / новости …).
- По дате.

## Подробности

Клик по записи раскрывает детали:
- Какой ресурс и какая запись.
- JSON изменений (иногда — «было / стало»).
- IP-адрес пользователя.
- Браузер (user agent).

## Что НЕ сохраняется

- **Пароли и секреты** — никогда.
- **Содержимое полей** — частично. Если нужно отследить, что именно
  поменяли — используй [Ревизии](./10-revisions.md). Активити-лог
  фиксирует факт действия, ревизии — содержимое.

## Сколько хранится

По умолчанию — **все записи**. Если журнал разросся и мешает работе,
разработчик может настроить автоочистку старых записей (например,
«удалять всё, что старше 6 месяцев»).

## Поиск

Поле поиска ищет:
- По email автора.
- По описанию действия.
- По названию затронутой записи.

## Экспорт

Нет кнопки экспорта в UI. Если нужно — разработчик может выгрузить CSV
через БД.

## Можно ли отключить логирование?

Не для юзера. Это контролируется кодом (разработчик). Логи важны для
безопасности и расследований, поэтому отключают их обычно только на
отдельных массовых операциях (импорт / сидинг).
