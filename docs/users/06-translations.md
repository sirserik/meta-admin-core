# 06. Переводы (ru / kk / en)

Сайт трёхъязычный. Админка помогает вводить переводы, но не заставляет —
можно начать с одного языка и добавлять остальные позже.

## Как выглядит переводимое поле

Любое поле, которое переводится, на форме рендерится так:

```
┌─[ RU  KK  EN ]─────────────────┐
│                                 │
│  [поле ввода]                   │
│                                 │
└─────────────────────────────────┘
```

Три вкладки сверху поля — языки. Активная вкладка подсвечена красным.
Клик по вкладке — ввод текста на этом языке.

Заголовок блока, подзаголовок, контент, название меню, лейблы термина
из словаря — **всё это переводится**. Обычные поля (статус, даты, URL,
настройки) — нет.

## Общий переключатель языка (сверху экрана)

В некоторых экранах сверху всей формы есть **синхронизированный**
переключатель — он переключает все переводимые поля одновременно. Удобно,
когда ты вводишь сразу все переводы для нового блока:

```
[ RU    KK    EN ]     ← переключатель для всей формы

Заголовок:     ___________________
Подзаголовок:  ___________________
Содержимое:    [визуальный редактор]
```

Переключился на `KK` — поля показывают казахскую версию. Вводишь,
переключился обратно — русская на месте.

## Что происходит, если язык не заполнен?

### На сайте

Если пользователь открыл казахскую версию, а перевод пустой — сайт
показывает **русский** текст (запасная локаль). Приоритет такой:

```
запрошенный язык → KK → RU → EN → сырое значение в БД
```

То есть:
- Если запросил `KK` и он пустой, подставится `RU`.
- Если и `RU` пустой — `EN`.
- Если всё пустое — отдельное значение из колонки `title` без перевода
  (это лежит в БД на случай старого контента).

### В админке

В списке ресурсов (например, «Новости») название показывается на **русском** —
это твой основной рабочий язык. Если хочешь проверить перевод, открой
запись и переключись на нужную вкладку.

## Какие поля переводимы — где узнать

### Блоки страниц

- ✅ Заголовок, подзаголовок, содержимое.
- ✅ Элементы внутри `data` — если разработчик объявил их переводимыми
  (в визуальном редакторе данных эти поля сами показывают вкладки
  `ru / kk / en`).
- ❌ Настройки, статус, даты, ссылки.

### Меню

- ✅ Название пункта.
- ✅ URL (каждый язык может вести на свой адрес).
- ❌ Иконка.

### Новости / Статьи / Программы

- ✅ Заголовок, краткое описание, содержимое.
- ❌ Slug (ЧПУ — всегда один).
- ❌ Дата публикации, категория.

### Словари (теги/категории)

- ✅ Название термина.
- ❌ Slug, порядковый номер.

## Работа с Tiptap (визуальный редактор)

В «Содержимом» блока используется **Tiptap** — современный редактор с
тулбаром:

```
[B] [I] [U]  |  [≡ H2] [≡ H3]  |  [• Список] [1. Список]  |  [🔗] [📷]
```

Базовые сочетания:

| Клавиши | Действие |
|---|---|
| Cmd/Ctrl + B | Жирный |
| Cmd/Ctrl + I | Курсив |
| Cmd/Ctrl + U | Подчёркнутый |
| Cmd/Ctrl + Z | Отменить |
| Cmd/Ctrl + Y / Cmd+Shift+Z | Повторить |
| Cmd/Ctrl + K | Вставить ссылку |

### Важные особенности

- **Копируешь из Word / Google Docs?** Редактор чистит лишние теги, но
  **картинки из Word не переносятся** (они копируются как base64). Если
  нужно сохранить картинку — загружай через иконку 📷 или перетаскивай
  из Finder.
- **Базовые стили** — редактор сам применяет стили сайта. Не нужно
  выбирать шрифты/цвета — это сделает дизайн.
- **Встраивание видео / iframe** — через тулбар «…» (эдвансед). Спроси
  разработчика, если не уверен.

## Как массово поменять переводы

Через интерфейс по одному полю. Для массового импорта (например, прислали
таблицу переводов) — попроси разработчика: он может загрузить их через
[импорт](../developers/26-artisan-commands.md).

## Проверка, что все языки заполнены

Открой страницу → проверь список блоков → зайди в каждый → переключись на
вкладки `KK` и `EN` → убедись, что поле не пустое.

На больших сайтах можно использовать `/admin/activity` — журнал активности,
чтобы увидеть, когда в последний раз редактировались переводы.

## Добавить новый язык

Технически возможно — нужна правка конфига разработчиком. Пакет
поддерживает любое количество локалей из коробки, но на текущих сайтах
(etec, meta) список зафиксирован на `ru / kk / en`.
