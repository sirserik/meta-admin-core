# 09. Словари (теги / категории)

Словарь — **набор ярлыков**, которые ты можешь приклеивать к любым записям:
к новости, к программе, к отчёту. Сразу становится проще группировать
контент и фильтровать его на сайте.

## Примеры

- Словарь **`tag`** — свободные теги: `наука`, `студентам`, `спорт`, `мероприятия`.
- Словарь **`category`** — категории: `первокурсникам`, `выпускникам`, `родителям`.
- Словарь **`audience`** — аудитории: `абитуриенты`, `работодатели`, `пресса`.

Сколько словарей нужно — решаешь ты. Добавляются на лету.

## Где это

**Сайдбар → Контент → Словари** (`/admin/taxonomies`).

## Интерфейс

```
┌──────────────────────────────────────┐
│ [ tag ] [ category ]   + новый словарь│
├──────────────────────────────────────┤
│ Новый термин в «tag»                  │
│ [Название_______] [Slug___]           │
│ + переводы (RU / KK / EN)             │
│ [Добавить]                            │
├──────────────────────────────────────┤
│ ● наука              #15 заявл.      │
│ ● студентам          #8              │
│ ● мероприятия        #42             │
└──────────────────────────────────────┘
```

Сверху — переключатель словарей. Клик по `tag` покажет термины этого
словаря, `category` — другого.

## Добавить термин

1. Переключись на нужный словарь (или создай новый — поле «+ новый словарь»).
2. Заполни **название** (то, что видит посетитель).
3. **Slug** — оставь пустым, сгенерируется автоматически. Если хочешь
   свой — заполни (только латинские буквы, цифры, дефисы: `higher-education`).
4. Переводы — для каждого языка своя подпись.
5. **Сортировка** — число. Меньше → выше в списке.
6. «Добавить».

## Создать новый словарь

Поле «+ новый словарь» сверху, введи короткое имя на латинице (`region`,
`subject`, `department`). После Enter откроется экран для этого словаря.

Словари без терминов исчезают после перезагрузки страницы (если ни одного
термина не создал).

## Редактирование термина

Клик по строчке термина в списке → поля заполняются сверху → меняешь →
«Сохранить».

## Удаление

Красная 🗑 справа от термина. **Осторожно:** термин отвяжется от всех
записей, которым он был прикреплён. Восстановить — только добавить вручную
заново и привязать.

## Как «прикрепить» термин к новости/программе/…

На форме записи (например, новости) есть секция «Теги» или «Категории» с
полем выбора. Начинаешь печатать — выпадают существующие термины, либо
добавляешь новый (`+ создать «тег»`). Несколько терминов через запятую.

Если на форме ресурса нет такого поля — значит, разработчик эту связку не
подключил. Спроси его.

## Показ на сайте

Что сайт делает с терминами — зависит от шаблона. Обычно:

- В конце статьи список тегов кликабельный — ведёт на `/tag/{slug}`.
- На странице «Новости» фильтр по категории.
- В Content API — фильтрация `?tag=наука,студентам`.

## Частые вопросы

### «Слаг `тег` не сохраняется, а становится tag»

Да, слаг автоматически транслитерирует кириллицу: `Тег` → `teg`. Чтобы
сделать свой, заполни вручную поле `Slug`.

### «Можно ли переименовать термин, уже прикреплённый к 50 записям?»

Да. Связи хранятся через внутренний ID, не через slug — переименование не
потеряет прикрепления. Но если у тебя есть прямые ссылки вида
`/tag/nauka` и ты меняешь слаг на `science` — старые ссылки перестанут
работать.

### «Как объединить два тега в один?»

Нет кнопки «merge» в интерфейсе. Нужно либо перепривязать каждую запись
руками, либо попросить разработчика через SQL.
