# 15. Сброс кэша

Если поменяли страницу / меню / настройки, но **на сайте старое видно** —
скорее всего, помогает сброс кэша.

## Где

**Сайдбар → Система → Кэш** (`/admin/cache`).

## Что происходит

Нажимаешь «**Очистить кэш**» → сервер удаляет:
- Кэшированный HTML страниц.
- Скомпилированные Blade-шаблоны.
- Кэш конфигурации, маршрутов, представлений.
- OPcache (если включён).

После сброса **первая загрузка страницы будет чуть медленнее** (админке
нужно пересобрать кэш), остальные — как обычно.

## Когда пригождается

### 1. «Поменял блок, а на сайте старое»

Причина: кэш страницы не успел обновиться. Сделай сброс — и обнови
страницу в браузере.

### 2. «Изменил меню, но ничего не поменялось»

Меню кэшируется сильнее, чем блоки. Сброс помогает.

### 3. «Загрузил новую картинку — она не открывается»

Это другой кэш — кэш браузера. Сделай hard-reload (Ctrl+F5 / Cmd+Shift+R).
Если не помогло — сервер тоже может кэшировать ссылки; тогда сброс
админки.

### 4. «Развернули обновление сайта, но интерфейс не обновился»

Скорее всего, скомпилированные Vue-бандлы остались в памяти. Сброс
кэша + обновление страницы админки.

## А редактирование не сбрасывает кэш автоматически?

Сбрасывает, но только для **конкретного блока / страницы**. Некоторые
агрегированные данные (меню, настройки, список программ) кэшируются
отдельно и не трогаются точечно — поэтому иногда нужен ручной сброс.

## Если после сброса ничего не изменилось

Возможные причины:
1. Кэш на стороне **Cloudflare** (если сайт за CDN) — нужно чистить там.
2. Кэш в **браузере** — Ctrl+F5.
3. Реальная ошибка в коде — нужен разработчик.
