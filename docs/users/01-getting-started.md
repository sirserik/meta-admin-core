# 01. Вход и первое знакомство

## Как попасть в админку

Открой адрес вашего сайта и добавь в конец `/admin`. Например:

```
https://etec.edu.kz/admin
```

Система покажет экран входа — введи email и пароль, которые тебе выдал
администратор.

Если пароля ещё нет:
1. Нажми «Забыли пароль?»
2. На почту придёт ссылка для сброса.
3. По ссылке задай новый пароль.

### Показать / скрыть пароль

Справа от поля «пароль» есть иконка с глазом 👁 — клик по ней переключает
между скрытым и открытым режимом. Полезно, когда нужно убедиться, что ты
набрал его правильно.

## Как устроен экран админки

После входа ты попадаешь на **Dashboard** (главный экран). Интерфейс поделён
на три зоны:

```
┌──────────────┬──────────────────────────────────────┐
│              │  ▸ Шапка: название сайта, поиск, тема │
│              ├──────────────────────────────────────┤
│   Сайдбар    │                                      │
│   (меню      │                                      │
│   слева)     │        Рабочая область               │
│              │        (список, форма, дашборд…)     │
│              │                                      │
└──────────────┴──────────────────────────────────────┘
```

### Сайдбар (слева)

Список всех разделов, сгруппирован по темам:

- **Главная** → дашборд.
- **Контент** → страницы, блоки, меню, медиа, словари, формы.
- **Школы, Сотрудники, Новости, Программы…** → конкретные разделы сайта.
- **Система** → настройки, бэкапы, кэш, права доступа, webhooks.

Раздел можно свернуть — клик по заголовку группы. Состояние сохраняется в
твоём браузере: при следующем входе всё будет как ты оставил.

### Шапка (сверху)

- **Логотип + название сайта** — клик возвращает на главный экран.
- **Поиск (Cmd+K / Ctrl+K)** — быстрый переход в любой раздел. Открывается
  палитра команд, начни вводить название.
- **Переключатель языка** — `ru / kk / en`. Переключает интерфейс **и**
  активную локаль при редактировании переводимых полей.
- **Твоя почта + кнопка «Выйти»** — справа, над рабочей областью.

### Рабочая область

Здесь открываются списки (например, «Школы»), формы редактирования, отчёты —
всё, что относится к выбранному разделу.

## Поиск по админке

Нажми **Cmd+K** (Mac) или **Ctrl+K** (Windows/Linux). Откроется окошко — введи
несколько букв из названия любого раздела:

```
[Cmd+K]   новос   →  Новости, Новость (создать)
```

Это самый быстрый способ перемещаться.

## Клавиатурные сокращения

| Клавиша | Действие |
|---|---|
| `Cmd/Ctrl + K` | Открыть палитру поиска |
| `Esc` | Закрыть модалку / палитру |
| `/` (в списке) | Поставить курсор в поле поиска |

## Тёмная тема

В правом верхнем углу есть переключатель темы. Решение сохраняется в браузере
на твоём устройстве; коллеги увидят своё настроение.

## Выход

Справа сверху — иконка человечка и кнопка «Выйти». Выйти принудительно нужно,
если ты работаешь с чужого устройства или забыл про себя. После выхода сайт
откроется на главной странице, как для обычного посетителя.
