# 18. Заявки и лиды

Отдельный раздел для **входящих обращений** — заявок на поступление,
консультаций, запросов на приёмную комиссию. Похож на «Заявки» из
[Форм](./08-forms.md), но заточен под конкретный сценарий колледжа /
вуза.

## Где

**Сайдбар → Система → Заявки** (`/admin/leads`).

## Чем отличается от форм

- **Формы** — гибкий конструктор (ты сам определяешь, какие поля).
- **Заявки (Leads)** — фиксированная структура: ФИО, телефон, email,
  программа, источник, комментарий. Полей не менять.

Это типичная «CRM-лайт» для приёмной комиссии / отдела маркетинга.

- 🟡 — спам / дубль.

## Действия

### Сменить статус

Выпадающий список:
- **Новая** — ещё не брали в работу.
- **В работе** — кто-то из комиссии взял, созванивается.
- **Обработана** — связались, отправили материалы / провели на консультацию.
- **Спам** — нерелевантно, можно удалять пачкой.

### Заметки

Поле для внутренних комментариев: «Перезвонить в пятницу», «Сестра уже
учится у нас — можно скидку», «Написал на email, жду ответа».

Заметки **видны всем** сотрудникам приёмной (они не приватные для автора).

### Удалить

Только для явного спама. По умолчанию — **не удаляй**, просто смени
статус на «Обработана», и запись уйдёт из активной выдачи.

## Фильтры

Сверху списка:
- По статусу.
- По программе (если колледж ведёт на несколько специальностей).
- По дате поступления.
- По источнику / UTM.
- Поиск по имени / телефону / email.

## Экспорт

Кнопка «**CSV**» — экспорт всех заявок в таблицу (для Excel / для
отправки маркетологам).

## Уведомления

Обычно настроены:
- На почту ответственному лицу (`@admission.etec.kz`) — при каждой новой.
- В Telegram/Slack канал приёмной (через [webhook](./13-webhooks.md)).

Если тебе должно приходить письмо, но не приходит — проверь с разработчиком,
включена ли рассылка и правильный ли email в настройках.

## Как заявки попадают в систему

- **Через форму на сайте** — посетитель заполнил «записаться».
- **API от партнёра** — отдельный канал (например, с Яндекс-форм).
- **Ручной ввод** — редко, но бывает, если пришли через звонок.

Ручной ввод из UI: кнопка «+ Новая заявка» сверху списка → открывается
та же форма деталей, только для создания.
