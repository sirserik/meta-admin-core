# 04. Каталог типов блоков

Справочник — что даёт каждый тип блока, когда его использовать, какие поля
он заполняет. Список зависит от сайта: разработчик может добавлять свои
типы. Ниже — типы, которые идут с пакетом «из коробки».

## Категории

В пикере типов (на форме «Новый блок») блоки сгруппированы:

- **Hero / Заголовки** — большие верхние секции.
- **Контент** — простой текст.
- **Медиа** — картинки, галерея, видео.
- **Списки / Данные** — структурированные блоки (статистика, преимущества,
  карточки).
- **Действия** — CTA, формы.
- **Системные** — низкоуровневые (один элемент фичи, одна карточка и т.д.).

## Основные типы

### `hero` — Главный баннер

Большой верхний блок страницы.

**Заполняемые поля:**
- Заголовок и подзаголовок.
- Фон — цвет или фото.
- Кнопки (1–3 штуки): текст + ссылка + стиль.

Используется один раз на странице, обычно первым.

### `heading` / `section-header` — Заголовок секции

Разделитель между другими блоками с крупным заголовком. Полезен, чтобы
отделить, например, «Преимущества» от «Отзывы».

### `content` — Текстовый блок

Простой блок с заголовком, подзаголовком и форматированным текстом.
Самый универсальный тип — подходит для любого статического текста
(история, описание, правила).

Поддерживает:
- Жирный, курсив, подчёркивание.
- Списки (нумерованные + маркированные).
- Ссылки.
- Заголовки h2, h3.
- Таблицы.
- Встроенные картинки (через медиатеку или загрузку).

### `default` — Простой блок

Мини-версия `content` — только заголовок + подзаголовок + короткий текст.
Используется для маленьких секций.

### `features` — Преимущества

3–6 карточек вида «Иконка + Заголовок + Короткое описание».

Используется на страницах услуг и «О нас», чтобы перечислить, почему
учиться/работать/купить стоит именно здесь.

**Данные:** список элементов `{icon, title, description}`.

### `stats` — Статистика

Ряд цифр с анимацией счёта при прокрутке: «75 лет», «15 000 выпускников».

**Данные:** список `{number, label, icon}`.

Когда использовать — не больше 4–6 цифр, иначе визуально перегружает.

### `cta` — Призыв к действию

Яркий блок с большой кнопкой. «Подать заявку», «Записаться на приём»,
«Связаться». Привлекает внимание за счёт контрастного фона.

Ставь **после** контентных блоков, когда читатель уже заинтересовался.

### `gallery` — Галерея

Сетка изображений. Клик открывает лайтбокс.

**Данные:** список картинок с подписями. Подписи переводимы по локалям.

### `links` — Ссылки / ресурсы

Карточки ссылок вида «Иконка + Заголовок + Описание + URL». Используется
для:
- Списка внешних ресурсов (РМЭБ, eLibrary, Google Scholar…).
- Категорий документов на странице отчётности.
- Партнёрских ссылок.

**Данные:** список `{url, title, description, icon}` с переводимыми полями.

### `testimonials` — Отзывы

Слайдер или сетка с отзывами: аватарка + имя + роль + текст.

### `faq` / `accordion` — Вопросы и ответы

Раскрывающиеся блоки. Пара «вопрос / ответ».

**Данные:** список `{question, answer}`, поддержка HTML в ответе.

### `timeline` — Хронология

События в виде вертикальной ленты. Используется для страниц истории,
календарей.

**Данные:** `{date, title, text}`.

### `video` — Видео

Встроенный плеер — YouTube, Vimeo или локальный файл. Принимает URL видео
и подгоняет плеер под рамки.

### `tabs` — Вкладки

Несколько подразделов на одном блоке — каждый со своим контентом.

### `partners` — Партнёры

Ряд логотипов (сетка или бегущая строка). Клик по логотипу ведёт на сайт
партнёра.

### `documents` — Документы

Список PDF/DOC-файлов с иконкой, названием и кнопкой скачать.

### `contacts_map` — Контакты + карта

Телефоны/адрес/часы работы + встроенная карта (Google/2GIS).

## Системные и вспомогательные

Эти типы обычно **не выбираются вручную** из пикера — их использует либо
разработчик, либо другие блоки ссылаются на них. Список есть в пикере на
случай, если нужно что-то починить.

- `feature_item` — один пункт в списке преимуществ. Используется внутри `features`.
- `program_card` — карточка образовательной программы.
- `stat`, `metric` — один показатель статистики.
- `form_option` — элемент выпадающего списка формы.
- `news_card` — одна карточка в секции новостей.
- `legal-document` — текст политики / договора.
- `contact` — одна запись контактов.
- `form` — встроенная форма (подача заявки).
- `image` — одно изображение.
- `settings` — конфигурационный блок (служебный).

## Советы по композиции страницы

### Главная страница — классика

```
1. hero
2. stats     — «чем мы гордимся»
3. features  — «наши программы/преимущества»
4. content   — развёрнутый рассказ
5. gallery   — фото с мероприятий
6. testimonials — отзывы студентов
7. cta       — «Поступи сейчас»
```

### Страница с отчётами

```
1. hero или heading — большой заголовок «Прозрачность»
2. content   — краткое описание
3. links     — список категорий документов
4. (повторяемые links — годовые отчёты, лицензии, уставные документы)
```

### Страница «О колледже»

```
1. hero
2. stats     — цифры
3. content   — краткая миссия
4. timeline  — история по годам
5. features  — ключевые ценности
```
