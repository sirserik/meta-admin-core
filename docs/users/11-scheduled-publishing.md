# 11. Запланированная публикация

«Опубликовать в понедельник в 8:00». «Снять баннер акции вечером в пятницу».
Делаешь заранее — админка сама поставит/уберёт.

## Где это

На форме редактирования **блока** (или любого другого ресурса, где
подключено) — карточка «**Публикация**» справа:

```
┌──────────────────────┐
│ Публикация           │
├──────────────────────┤
│ Статус               │
│ [Черновик        ▾] │
│ ☐ Активен            │
│                       │
│ Опубликовать в       │
│ [📅 02.05.2026 08:00]│
│                       │
│ Снять с публикации в │
│ [📅 15.05.2026 18:00]│
│                       │
│  [Сохранить]          │
└──────────────────────┘
```

## Как это работает

1. Ставишь статус «**Черновик**» (иначе блок сразу виден).
2. В поле **«Опубликовать в»** выбираешь дату и время из календаря.
3. Опционально ставишь **«Снять с публикации в»** (если это временный
   баннер / акция / объявление).
4. Сохраняешь.

Админка **раз в минуту** проверяет все блоки:
- если у черновика наступило `publish_at` → статус меняется на
  «Опубликовано»;
- если у опубликованного наступило `unpublish_at` → статус меняется на
  «Черновик».

Так что точность — ±1 минута.

## Два режима

### A) Автопубликация

```
Статус: Черновик
publish_at: 02.05.2026 08:00
unpublish_at: (пусто)
```

Блок невиден до 2 мая 8:00. Потом автоматически публикуется и остаётся
навсегда (пока ты не снимешь вручную).

### B) Временная публикация

```
Статус: Опубликовано   (или Черновик с publish_at)
publish_at: 01.05.2026 00:00
unpublish_at: 10.05.2026 23:59
```

Блок активен с 1 по 10 мая. До — невидим, после — невидим.

### C) Убрать без автовключения

Оставь `publish_at` пустым, заполни только `unpublish_at`.

## Что если я хочу опубликовать прямо сейчас?

Просто поставь статус «Опубликовано» и оставь поля дат пустыми. Расписание
нужно **только когда хочешь отложить**.

## Что если расписание не сработало?

Нужно, чтобы на сервере был запущен **cron** (это настраивает разработчик
один раз при деплое). Если не настроен — расписание не сработает: статус
останется «Черновик» на вечно, а блок не появится на сайте.

Как проверить, что cron живой — попроси разработчика запустить
`php artisan admin-core:apply-schedule --dry-run` и посмотреть, что
увидит команда. Она покажет список ожидающих публикации блоков.

## Для каких ресурсов это работает

Сейчас «из коробки» — для **блоков страниц** (`PageBlock`). Для других
типов контента (новости, статьи) разработчик подключает отдельно — спроси
его, если надо.

## Частые вопросы

### «Я выбрал дату в прошлом — что будет?»

Блок опубликуется при ближайшем запуске cron — через минуту-две.

### «Можно ли менять запланированное?»

Да. Открой блок, измени дату, сохрани. Сохранение **перезапишет** старое
расписание.

### «Я поставил publish_at, но статус Опубликовано — это конфликт?»

Нет. Если статус уже «Опубликовано», `publish_at` игнорируется (блок уже
виден). Но `unpublish_at` всё ещё сработает.

### «Почему при расписании желательно статус Черновик?»

Чтобы до часа X блок не был виден случайно. Иначе он уже опубликован, и
запланированная дата «достанется» только для логов.
