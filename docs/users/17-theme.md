# 17. Тема сайта

Палитра цветов сайта — главный цвет бренда, акценты, фон. Меняется не
через код, а через визуальный редактор.

## Где

**Сайдбар → Система → Тема сайта** (`/admin/theme`).

## Что можно поменять

Набор «design tokens» — именованных цветов:

- **Primary** — главный цвет бренда (кнопки, ссылки). Обычно меняют только
  его.
- **Primary-hover / active** — оттенки при наведении/клике.
- **Accent** — дополнительный акцент (например, уведомления, промо-баннеры).
- **Danger / Warning / Success** — красный / жёлтый / зелёный для
  сообщений об ошибках и успехе.
- **Foreground / Background** — основной текст и фон страницы (светлый
  режим).
- **Dark-mode варианты** этих же токенов.

## Редактор

```
Primary         [#C41E3A]  ████████  Пипетка🎨
Primary-hover   [#9a1729]  ████████  Пипетка🎨
Accent          [#2563EB]  ████████  Пипетка🎨
…
```

- Color picker — клик по квадрату цвета.
- Поле HEX — ввод вручную (например, `#C41E3A`).
- Кнопка «Пипетка» — скопировать цвет с экрана (зависит от браузера).

## Предпросмотр

Большинство экранов админки перерисовываются **сразу** — сохраняется
состояние в памяти браузера, реальная запись в БД идёт на кнопке
«Сохранить».

## Сохранение

Кнопка «**Сохранить**» внизу. Цвета попадают в таблицу `settings` и
начинают применяться и на **сайте**, и на **админке**.

## Сброс на дефолт

Кнопка «Сбросить» вернёт все токены к их начальным значениям (те, что
разработчик указал в пакете).

## Частые вопросы

### «Поменял цвет — а на сайте не обновилось»

1. [Сбрось кэш](./15-cache.md).
2. Hard-reload страницы (Ctrl+F5).
3. Если ничего — возможно, этот конкретный блок на сайте вёрстан с
   хардкодом цвета (в шаблоне, не через токен). Попроси разработчика
   обновить.

### «Хочу полностью переделать дизайн»

Темизация через токены — поверхностная. Радикальная смена дизайна
(другая типографика, макет, компоненты) = работа разработчика.

### «Есть пресеты (красный / синий / зелёный)?»

Зависит от сайта. Если разработчик добавил пресеты — они будут как
кнопки сверху экрана («Применить пресет: etec-red»). Если нет — меняешь
каждый токен руками.
