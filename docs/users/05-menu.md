# 05. Меню сайта

Верхняя и нижняя навигация сайта — то, что видит любой посетитель. Меню
редактируется в одном месте: **Сайдбар → Система → Меню**
(`/admin/menu`).

## Как устроено

Меню — **дерево**: у каждого пункта есть родитель и свой порядок. Верхний
уровень — пункты в горизонтальной полосе сайта. Вложенные пункты —
подменю, которое раскрывается по наведению/клику.

Пример дерева:

```
О колледже
├── История
├── Руководство
└── Аккредитация
Поступление
├── Приёмная комиссия
├── Список программ
└── Иностранным студентам
Контакты
```

Раскладка на сайте берётся отсюда: порядок пунктов, тексты для каждого
языка, целевые URL.

## Основной список

Открыв `/admin/menu`, увидишь:

```
┌─────────────────────────────┐
│ ○ О колледже                │
│   └ ○ История              │
│   └ ○ Руководство           │
│ ○ Поступление               │
│   └ ○ Приёмная комиссия     │
│ ○ Новости                   │
│ ○ Контакты                  │
└─────────────────────────────┘
```

- `○` — пункт меню (кликни, чтобы редактировать).
- Вложенность показывается отступом слева.
- «Драг-энд-дроп» — перетаскивание меняет порядок и уровень.

## Создать новый пункт

1. Нажми «**+ Новый пункт**».
2. Заполни:
   - **Название** — тексты на трёх языках (`ru / kk / en`).
   - **Адрес** — куда ведёт (можно разный для каждого языка, например
     `/ru/about` и `/kk/kolledj-turaly`).
   - **Родитель** — если пункт вложен, выбери родительский. Или оставь
     «(корень)» для верхнего уровня.
   - **Иконка** — FontAwesome-класс (`fa-graduation-cap`). Опционально.
   - **Активен** — галочка. Сняв её, пункт спрячется с сайта, но
     останется в админке.
3. Сохранить.

## Редактировать / удалить

Клик по пункту открывает форму. Удаление — красная кнопка внизу формы.
Важное: если у пункта есть подпункты, они **не удаляются**, а переходят
в корень. Это защита от случайного уничтожения целой секции.

## Содержимое ссылки: три варианта

- **Внешняя** — абсолютный URL, например `https://lirotech.kz`.
- **Внутренняя (страница сайта)** — относительный путь `/about`,
  `/programs/computer-science`, `/kk/news/123`.
- **Якорь** — `#contacts` ведёт к якорю на текущей странице
  (используется редко).

URL можно указать **разный для каждой локали** — это нужно, если у разных
языковых версий сайта разные slugи. Если заполнено только русское поле,
админка считает, что путь одинаковый.

## Включить / выключить пункт

Галочка «Активен» на форме пункта. Выключенный пункт останется в списке,
но не покажется на сайте. Удобно, чтобы временно спрятать раздел без
потери настроек.

## Порядок

Меняется перетаскиванием (drag-and-drop). Порядковый номер (`menu_order`)
обновляется автоматически. Вручную выставлять не нужно.

## Частые ошибки

### «Пункт не появился на сайте»

- Галочка «Активен» включена?
- Этот сайт действительно использует эту функцию? (см. с разработчиком —
  может, шаблон верстает меню руками из `routes/`).
- Сбрось кэш.

### «У меня одинаковое меню в верхнем и нижнем хедере»

На многих сайтах меню в футере — отдельная структура. В этом случае его
либо настраивают в коде, либо через **отдельные специальные пункты с
префиксом**. Спроси разработчика.

### «После перетаскивания порядок не сохранился»

Проверь, был ли интернет во время перетаскивания — перенос отправляется
на сервер. Если была ошибка, обнови страницу и перетащи заново.
