# 16. Общие настройки сайта

Набор «ручек», которые меняют что-то глобально на сайте. Обычно это:
соцсети в футере, контакты директора, тумблеры меню, вторичный логотип.

## Где

**Сайдбар → Система → Общие** (`/admin/site-settings`).

## Что можно настроить

### Соцсети

Список ссылок, которые появятся в футере (и иногда в хедере):

- Facebook, Instagram, TikTok, Telegram, WhatsApp, YouTube, VKontakte,
  LinkedIn — у каждого своё поле с URL.
- Пустое поле → иконка не покажется.

Пример:

```
Instagram  [https://instagram.com/etec.kz]
Telegram   [https://t.me/etec_kz        ]
Facebook   [                            ]   ← не покажется
```

### Контакты

Плашка, которая обычно показывается на страницах «Контакты» и в футере:

- Телефон.
- Email.
- Адрес.
- Часы работы.

Поля многоязычные (`ru / kk / en`). В footer'е показывается на локали
посетителя.

### Контакты директора / ректора

Отдельный блок: имя, должность, фото, телефон, email. Показывается в
секции «Вопрос ректору» и на странице руководства.

### Тумблеры меню

Список чекбоксов вида «Показывать в меню раздел …» — позволяет временно
скрыть какую-то секцию сайта, не удаляя её и не трогая меню напрямую.

Пример:
```
☑ Показывать «Новости»
☑ Показывать «Программы»
☐ Показывать «Блог»          ← скрыто
```

### Вторичный логотип

Отдельный логотип для мобилки / печати / подвала. Загружается так же, как
любая картинка — кнопкой выбора файла.

### Прочие настройки

Разработчик может добавлять свои настройки (`GOOGLE_ANALYTICS_ID`,
`RECAPTCHA_SITE_KEY`, «показывать всплывающее окно», и т.п.). Они тоже
попадают сюда, если разработчик зарегистрировал.

## Как сохраняется

Все настройки хранятся в таблице `settings` (ключ-значение). Админка
группирует их по смыслу и показывает формы по группам. Сохранение точечное:
нажимаешь «Сохранить» на конкретной секции, меняются только её поля.

## Смотрим на результат

После сохранения — обнови сайт в другой вкладке (Ctrl+F5) и посмотри
футер / страницу контактов. Если что-то не видно — скинь [кэш](./15-cache.md).

## Как сбросить всё на дефолты

Отдельной кнопки нет. Если накрутил, и не понимаешь, как вернуть —
попроси разработчика, у него есть сидер с дефолтными значениями.
